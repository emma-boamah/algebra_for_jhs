# Algebra for JHS

An interactive browser-based introduction to algebra for Junior High School learners.

## Activities

- **Equation balance:** solve simple one-step and two-step equations. Choose inverse operations and see the solution steps.
- **Substitution:** evaluate expressions by choosing a value for `x`.
- **Number patterns:** identify arithmetic and multiplication rules, then enter the next two terms.
- **Practice quiz:** four multiple-choice questions with immediate feedback, explanations, score, and retry.
- Responsive design with no build process or JavaScript dependencies.

## Run locally

Open `index.html` in a current browser, or start a local static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

In the repo, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. GitHub Pages will display the published URL after deployment completes.

## Algebra ideas covered

- Solving equations with inverse operations while keeping both sides equal.
- Substitution and order of operations.
- Combining like terms in a quiz example.
- Recognising and extending number sequences.

## Files

- `index.html` — activities and page structure
- `styles.css` — responsive visual design
- `script.js` — equation, substitution, pattern, and quiz interactions
